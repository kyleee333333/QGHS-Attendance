# G11 Review — Philippines (Static Site)

This is a simple static site scaffold for Grade 11 review materials (Philippines).

Files:
- `index.html` — home page
- `subjects.html` — list of subjects and links
- `math.html`, `science.html`, `english.html`, `filipino.html` — sample subject pages
- `resources.html` — links & downloads
- `contact.html` — contact info
- `style.css` — simple styles
- `script.js` — small quiz handler

Preview locally (PowerShell):

```powershell
# from this folder:
cd "c:\Users\jempe\Desktop\offline exam\g11-review-site"
python -m http.server 8000; # then open http://localhost:8000
```

If you prefer no server, you can open `index.html` directly in the browser, but some browsers restrict local JS for complex features.
